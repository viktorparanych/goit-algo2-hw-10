# Висновки до Завдання 1 Порівняння алгоритмів QuickSort

В результаті емпіричного аналізу обох алгоритмів на масивах випадкових чисел розміром від 10 000 до 500 000 елементів можна зробити наступні висновки:

1. **Часова складність:** Обидва алгоритми на практиці демонструють час виконання, що відповідає теоретичній складності $O(N \log N)$. На графіку видно, що час зростає лінійно-логарифмічно зі збільшенням розміру масиву, без різких стрибків.
2. **Порівняння швидкодії:** Детермінований та рандомізований підходи показують майже ідентичний час виконання на випадково згенерованих даних. Іноді детермінований алгоритм працює мікроскопічно швидше, оскільки рандомізований витрачає додатковий час на виклик функції `random.choice()` на кожному кроці рекурсії.
3. **Стійкість до найгіршого випадку:** Хоча на випадкових даних різниці майже немає, рандомізований QuickSort має перевагу у тому, що він математично захищений від найгіршого випадку $O(N^2)$ на специфічно відсортованих даних що робить його більш універсальним для реальних систем. Детермінований підхід з вибором середнього елемента також є ефективним і запобігає деградації на вже відсортованих масивах.

**Загальний висновок:** Обидва алгоритми є високоефективними для сортування великих масивів, проте рандомізований підхід забезпечує надійнішу гарантію уникнення найгіршого випадку на будь-яких вхідних даних.# goit-algo2-hw-10
